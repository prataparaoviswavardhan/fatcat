Put the 32 cat photos in this folder, named by cat number:

  1.jpg  2.jpg  3.jpg  ...  32.jpg

If a photo has a different extension (.jpeg or .png), change the "image" line
for that cat in src/data/cats.js, for example image: "cats/7.jpeg".

Tip: resize photos to about 1000 pixels wide before adding them. Phone photos are
often several MB, which makes the site slow on phones.
